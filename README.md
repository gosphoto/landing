# Госфото — лендинг

Фото для Госуслуг онлайн. Домен/репо: `gosphoto` = **гос** + фото (не английское «Go»).

Дизайн в духе PhotoAiD: светлый фон, жёлтый акцент, hero с до/после.

## Локально

```bash
python3 -m http.server 5173
```

http://localhost:5173

## Структура

- `index.html` — страница
- `css/styles.css` — стили
- `assets/` — hero и карточки до/после

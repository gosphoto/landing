# GoSphoto landing

Лендинг сервиса фото на документы (дизайн в духе PhotoAiD: светлый фон, жёлтый акцент, hero с до/после).

## Локально

Открой `index.html` в браузере или:

```bash
python3 -m http.server 5173
```

Затем http://localhost:5173

## Структура

- `index.html` — страница
- `css/styles.css` — стили
- `assets/` — hero и карточки до/после

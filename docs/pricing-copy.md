# Копирайт: превью и цена 499 ₽

> Проверено: 2026-11-08 · источники: эта сессия

## Вердикт

Пользователю явно говорим: **превью бесплатно**, готовый файл — **499 ₽ разово**. В текстах — «превью», не «предпросмотр».

**С чего начать:** те же формулировки на главной, CTA посадок и note на `result.html`.

## Канон формулировок

| Место | Текст |
|-------|--------|
| Trust / короткая строка | `Превью бесплатно · 499 ₽` |
| CTA / абзац | `Превью бесплатно. 499 ₽ — разовая оплата готового файла.` |
| Шаг «как работает» (`index`) | `Превью бесплатно. Готовый файл — 499 ₽ разово, если всё устраивает.` |
| Note на result (неоплачено) | `{price} ₽ — разовая оплата: JPEG для Госуслуг и лист 10×15.` |

Цена на кнопке: `Скачать за 499 ₽` (или `price_rub` с бэка).

## Где стоит

| Файл | Что |
|------|-----|
| `index.html` | hero-trust, шаг 03, CTA `#start` |
| `result.html` | статичный note + JS при unpaid |
| `foto-na-pasport.html`, `foto-na-zagranpasport.html` | CTA |
| `kak-sdelat-…`, `ne-prinimaet-…`, `trebovaniya-k-…` (3 шт.) | CTA; на `trebovaniya-k-foto-na-gosuslugi` ещё trust |

## Тон

- Коротко, по делу, без «тарифов» и подписок.
- Лексика продукта: превью, файл / JPEG, Госуслуги, разовая оплата.
- Не писать «предпросмотр» в UI.
